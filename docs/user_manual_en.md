## Introduction

Login AWP is a plugin that enhances the WordPress login screen with powerful customization features. With this plugin, you can completely transform the appearance of your login page without any coding knowledge.

### Key Features

- **Logo Customization**: Upload your own logo to replace the default WordPress icon.
- **Background Images**: Add a custom background image with elegant transitions.
- **Pre-designed Themes**: Choose from a variety of pre-designed themes with a single click.
- **Visual Style Builder**: Customize colors, fonts, borders, spacing, and more using an intuitive visual interface.
- **Responsive Design**: Perfect display on all devices, from mobile to desktop screens.
- **Multilingual Support**: Available in English and Spanish.

## Installation

There are two ways to install the Login AWP plugin:

### Through the WordPress Plugin Directory

1. In your WordPress admin panel, go to **Plugins → Add New**.
2. Search for "Login AWP" in the search field.
3. Click **Install Now** next to "Login AWP".
4. Once installed, click **Activate**.

### By Manual Upload

1. Download the latest version of the plugin from [wordpress.org](https://wordpress.org/plugins/login-awp/).
2. In your WordPress admin panel, go to **Plugins → Add New → Upload Plugin**.
3. Select the downloaded ZIP file and click **Install Now**.
4. Once installed, click **Activate**.

## General Configuration

To access the plugin settings:

1. Go to **Appearance → Login** in your WordPress admin panel.
2. The first tab you'll see is "General", where you can configure the basic options.

### Logo Customization

To change the logo that appears on the login screen:

1. In the "General" tab, find the "Logo" section.
2. Click the **Select Image** button.
3. Upload a new image or select one from the media library.
4. Click **Select** and then **Save Changes**.

**Recommendations for the logo:**
- Ideal size: 320px × 80px
- Recommended formats: PNG or SVG (for better quality)
- Use images with a transparent background for better integration

To remove the custom logo and revert to the default WordPress logo:
1. Click the **Delete Image** button.
2. Save the changes.

## Background Customization

To change the background image of the login screen:

1. In the **Appearance → Login** menu, select the "Background" tab.
2. Click the **Select Image** button.
3. Upload a new image or select one from the media library.
4. Click **Select** and then **Save Changes**.

**Recommendations for the background image:**
- Recommended resolution: 1920px × 1080px or higher
- Optimal size: Less than 500KB (for fast loading times)
- Recommended formats: JPG or WEBP (better quality/size ratio)
- Consider using images that aren't too colorful or detailed to maintain readability

## Pre-designed Themes

Login AWP includes several pre-designed themes that you can apply with a single click:

1. In the **Appearance → Login** menu, select the "Themes" tab.
2. A gallery of available themes will be displayed.
3. To preview a theme, click the **Preview** button.
4. To apply a theme, click the **Select Theme** button.

Pre-designed themes automatically change the complete appearance of the login page, including colors, styles, and element layout.

## Style Builder

The Style Builder allows you to completely customize every visual aspect of the login page:

1. In the **Appearance → Login** menu, select the "Style Builder" tab.
2. On the left, you'll see control panels for different elements.
3. On the right, a real-time preview of your changes will be displayed.

### Color Customization

You can modify the colors of all elements:
- **Form Background**: Color of the panel where the login form is located.
- **Text**: Color of general text and links.
- **Input Fields**: Background color and borders of the username and password fields.
- **Login Button**: Background color, text, and borders of the button.

### Typography Customization

To change the font:
1. Select a font family from the dropdown menu.
2. Adjust the text size using the slider controls.

### Border and Spacing Customization

1. Use the controls to adjust the border radius (for more or less rounded corners).
2. Modify the internal spacing (padding) to expand or reduce the space inside elements.
3. Adjust margins to control the separation between elements.

### Apply and Save Styles

Once you have made all desired changes:
1. Check the appearance in the preview.
2. Click **Save Styles** to apply the changes.

## Frequently Asked Questions

### Can I use my own custom CSS?
Yes, in the "Style Builder" tab you'll find a text area for custom CSS where you can add your own style rules.

### Does the plugin affect my site's performance?
No. Login AWP only loads its resources on the login page, without affecting the performance of the rest of the site.

### Is it compatible with other security plugins?
Yes, Login AWP is compatible with most security plugins and login attempt limiting plugins.

### Does it work with two-factor authentication?
Yes, it works perfectly with two-factor authentication plugins.

### Can it be used on WordPress multisite installations?
Yes, the plugin is fully compatible with multisite installations.

## Troubleshooting

### The login page doesn't show my changes
1. **Clear cache**: Clean your browser's cache or use incognito mode to verify.
2. **Plugin conflicts**: Temporarily deactivate other plugins that might be modifying the login page.
3. **CSS conflicts**: If you're using custom CSS, check for conflicting rules.

### Background images are slow to load
1. Optimize the size of your image. We recommend files under 500KB.
2. Convert the image to WEBP format for better performance.

### The logo appears distorted
1. Make sure you use a high-quality image with the recommended dimensions.
2. Verify that the image has the correct aspect ratio.

## Uninstallation

If you wish to uninstall the plugin:

1. Go to **Plugins** in your WordPress admin panel.
2. Find "Login AWP" in the list.
3. Click **Deactivate**.
4. If you want to provide feedback on why you're deactivating the plugin, you can complete the form that appears.
5. To completely remove the plugin, click **Delete**.

**Note**: When uninstalling the plugin, all custom settings will be removed.
